Utility usage

This file shows the utility calls only. The participant screens, consent, and trial data belong in the experiment.

async function generateForOneTrial(passwordFromTheSurveyResponse, rawSubmission) {
  let apiKey = await FeedbackUtils.decryptApiKey(
    window.ENCRYPTED_API_KEY,
    passwordFromTheSurveyResponse
  );
  try {
    const result = await FeedbackUtils.generate({
      apiKey,
      model: "gpt-6-luna",
      reasoningEffort: "none",
      temperature: 0.3,
      maxOutputTokens: 1000,
      systemPrompt: "Study-specific instruction",
      text: rawSubmission
    });
    // Record result.text in the generation trial.
  } finally {
    apiKey = null;
  }
}

Do not store password or apiKey in trial data, browser storage, or logs. See README.md for the Cognition plugin and stylesheet requirements.
