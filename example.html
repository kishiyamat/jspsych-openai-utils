Utility usage

The utility handles API-key decryption and the OpenAI request. Keep the password and decrypted key out of trial data.

const authentication = {
  type: jsPsychCallFunction,
  async: true,
  func: done => FeedbackUtils.decryptApiKey(
    window.ENCRYPTED_API_KEY,
    passwordFromSurvey,
    done
  )
};

const generation = {
  type: jsPsychCallFunction,
  async: true,
  func: done => FeedbackUtils.generate({
    model: "gpt-6-luna",
    reasoningEffort: "none",
    temperature: 0.3,
    maxOutputTokens: 1000,
    systemPrompt: "Study-specific instruction",
    text: rawSubmission
  }, done)
};

FeedbackUtils.clearKey();

Use the returned safe fields in the experiment's own trial data. See README.md for Cognition plugin and stylesheet requirements.
